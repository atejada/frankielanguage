    What is this repo?

    This is the documentation site for the Frankie Programming Language (v1.21.0) — a procedural language with Ruby-inspired syntax that compiles to Python. Docs are written in Markdown and served as a static site.

    The Frankie compiler itself lives in a separate repo (/Documents/GitHub/Frankie). This repo is docs only.

    🧊 Frozen for the Book

    Frankie is language-frozen as of v1.21.0 — Blag is writing "The Book of Frankie" against this exact version. Until the freeze lifts: no new syntax, no stdlib/stitch signature changes, no breaking behavior changes get documented here. Patch releases (bug fixes, doc corrections) still land normally — keep these docs in sync with those. If asked to document a language feature that doesn't exist yet in the compiler repo during the freeze, say so rather than speculating.

    Conventions

    • Each data type, stdlib module, and stitch has its own dedicated page.
    • reference/full_index.md is the canonical single-page stdlib reference — keep it in sync when adding/changing stdlib functions.
    • Example .fk files in examples/ are real, runnable Frankie programs (test them against the compiler when updating).
    • getting_started/changelog.md tracks version history — update it for every Frankie version bump.
    • Docs target Frankie v1.21.0 unless explicitly updating to a new version.

    Frankie language quick reference (for writing accurate docs)

    • Compiler pipeline: .fk → Lexer → AST → CodeGen → Python → exec()
    • No external dependencies — pure Python 3.10+
    • Stitches are loaded with stitch "frankieconfig" (not import)
    • require "file" merges into scope; import "file" as name (v1.17) loads into its own namespace
    • error, import and test are contextual keywords (v1.17) — only special in statement position
    • enum, benchmark and breakpoint are contextual keywords too (v1.18)
    • Numeric literals support underscores (1_000_000) and scientific notation (2.5e-3) since v1.18
    • Gradual type annotations (def area(r: Float) -> Float) since v1.19 — optional, checked statically only
    • Frankie installs via Homebrew (brew install atejada/frankie/frankie), git clone + install.py, or unpacked zip; frankiec examples [name] lists/copies bundled examples regardless of install method
    • frankiegame and frankiecanvas (v1.20) share one game-engine API; v1.21 added load_image/draw_image (real PNG sprites in frankiecanvas, ▒ placeholder in frankiegame) and synth_play (WebAudio tones in frankiecanvas, terminal bell in frankiegame) to both
    • Integer division uses //, exponentiation uses ** (Fortran heritage)
    • ? identifiers compile to _q, ! to _bang in generated Python
    • Test assertions: assert_eq, assert_true, assert_match, assert_nil, assert_raises, assert_raises_typed
